# BTube 

Um App desktop para download de vídeos, desenvolvido pela KCorporation.

##  Características

-  Downloads rápidos com yt-dlp
-  Suporte a áudio (MP3, M4A, WAV, FLAC)
-  Gerenciamento de downloads simultâneos
-  Biblioteca integrada

##  Instalação

```bash
# Clone o repositório
git clone https://github.com/bkapa8/kcorp_btube.git
cd btube

# Instale as dependências
pip install -r d.txt

# Execute
python src/main.py
